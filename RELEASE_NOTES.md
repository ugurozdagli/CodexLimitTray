# CodexLimitTray v1.2.0

**For Codex addicts. Just one more prompt.**

The first public CLT release puts your remaining short-term and weekly Codex limits in a compact two-line Windows taskbar widget.

## Included

- Simple and Detailed views, local reset times, color-coded remaining percentages.
- Rounded dark usage panel with smooth text and countdowns.
- Automatic refresh every 60 seconds, manual refresh, move/lock/reset controls.
- Optional start with Windows and a small tray fallback.
- Turkish interface. Project documentation is in English, with a Turkish guide.

## Download

Run `CodexLimitTray-v1.2.0-win-x64.exe` directly for a portable single-file experience, or extract `CodexLimitTray-v1.2.0-win-x64.zip` and run `CodexLimitTray.exe`. The .NET runtime is included. You still need your own installed Codex application/CLI and a signed-in ChatGPT account.

Target: Windows 11 x64, primary monitor, horizontal taskbar. The initial build is unsigned. No maintainer account, API key, or session files are included.

Verify your EXE or ZIP against `SHA256SUMS.txt` and the GitHub build-provenance attestation. Attestations identify the build's source/workflow and do not replace Windows code signing or an independent security review. Read the README and privacy/security documents before use.
